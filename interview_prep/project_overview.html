AI 智能笔记 · 整体架构与问答流程
依据项目源码整理 · 技术栈:React+TS / FastAPI / MySQL / Milvus / LangChain / BGE-Reranker
① 系统架构(三层)
前端层
React 18 + TypeScript + Vite · Tiptap 富文本 · Zustand · i18n 双语
页面:登录注册 / 笔记列表·编辑器 / AI 对话 / 会话管理 / 知识库 / 每日回顾 / 设置
后端层
FastAPI + SQLAlchemy(async) + AIOMySQL
Router(agent/note/template/user/health) → Service(Agent/Note/Chat/Template) → Repository → Model
RAG 模块:NoteRagService → 混合检索(向量+BM25) → 重排(CrossEncoder)
数据/外部
MySQL 用户·笔记·会话·模板 | Milvus 笔记向量库(按 user_id 隔离) | LLM API OpenAI 兼容(Qwen) | BGE-Reranker 本地模型 | Embedding API
② AI 问答端到端流程(核心链路)
1
前端发起 · AIChat 页 POST /chat/agent/query/stream,携带 JWT,走 SSE 流式
2
鉴权与会话 · JWT 解析 user_id;有 session_id 则复用,否则新建会话并生成标题;用户消息落库(MySQL chat_messages)
3
RAG 召回 · Ensemble 混合检索:Milvus 语义向量 + BM25 关键词,按问题长度/词密度动态调权,按 user_id 过滤 → top5
4
重排精筛 · BGE-Reranker-v2-m3 交叉编码器(query×文档打分)重排,取 top3 作为上下文
5
组装 Prompt · System(助手设定+检索到的笔记)+ 历史消息 + 当前问题,构建 LangChain Tool-Calling Agent(工具:笔记统计)
6
流式生成 · AgentExecutor.astream 调 LLM;可多轮工具调用(max 3 轮);AI 回答落库
7
SSE 回传 · thinking(分析中/调工具)→ response(流式文本) → done;前端 useSSE 解析,Markdown 增量渲染,中断可 AbortController 取消
③ 笔记数据双写一致性
写 笔记增/改/删 → MySQL 事务提交 → 同步 upsert/delete 向量到 Milvus(失败仅记日志,不阻塞主流程)
读 列表/搜索走 MySQL(LIKE 查询);AI 问答走 Milvus 向量 + BM25,数据按 user_id 严格隔离
